# Spatial Interaction Models, Graphs, & Networks

Graphs are a fundamental data structure that are incredibly powerful and commonly used in geospatial applications, for everything from routing to hydrological modeling. Graphs are a way that we can abstract networks across space, amongst other dimensions, whether it be time, the internet, or infrastructure. One such technique that we can use graphs to solve in spatial data science is spatial interaction models, which allow us to understand how entities interact with one another throughout space.
